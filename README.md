# Sistem Manajemen Data Mahasiswa (PHP Native + MySQL)

## Cara Menggunakan di VS Code:
1. Ekstrak file .zip ini di dalam folder `htdocs` milik XAMPP Anda.
   (Misalnya ekstrak menjadi `C:/xampp/htdocs/sim_mahasiswa/`).
2. Buka folder `sim_mahasiswa` tersebut di **VS Code** (Klik `File` -> `Open Folder`).
3. Jalankan **Apache** dan **MySQL** melalui panel kontrol XAMPP.
4. Buka http://localhost/phpmyadmin/ di browser Anda.
5. Jalankan query SQL yang ada di file `database.sql` untuk membuat tabel beserta data dummy (admin/admin123).
6. Buka URL: http://localhost/sim_mahasiswa/ untuk melihat hasilnya.
